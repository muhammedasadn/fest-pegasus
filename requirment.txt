# Package Manager:  pnpm >= 12.0.0 (Strictly pinned to pnpm@12.4.2 in package.json)

# To install pnpm globally via npm:
#   npm install -g pnpm@12.4.2

# ------------------------------------------------------------------------------
# 2. STEP-BY-STEP INSTALLATION & RUN INSTRUCTIONS
# ------------------------------------------------------------------------------
# 1. Clone repository and navigate to root directory:
#      git clone <repo-url>
#      cd fest-pegasus
#
# 2. Install all dependencies using pnpm:
#      pnpm install
#
# 3. Configure Environment Variables (Optional for local dev, required for Supabase):
#      cp .env.example .env.local
#      (Fill in NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY)
#
# 4. Start local development server:
#      pnpm dev
#      Server will be available at: http://localhost:3000
#
# 5. Production build and execution:
#      pnpm build
#      pnpm start
